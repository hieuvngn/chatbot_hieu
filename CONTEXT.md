# CourseMate RAG Chatbot

A demo chatbot for IT students: advises on course selection and answers knowledge questions grounded in study materials, using a retrieval-augmented generation pipeline.

## Language

**Course advisory**:
The task of recommending and explaining courses to a student from structured data (syllabus, credits, prerequisites). Task (a).
_Avoid_: Chọn môn, course selection, recommendation task

**Knowledge Q&A**:
The task of answering a student's question about a topic, grounded in study documents with visible citations. Task (b).
_Avoid_: Material retrieval, hỏi đáp tài liệu

**Source**:
A unit of retrieved material that an answer cites — at document or chapter granularity, never a raw chunk.
_Avoid_: Chunk, reference, context fragment

**Citation**:
The visible reference a generated answer carries back to its Source, shown in the UI and clickable by the user.
_Avoid_: Nguồn (as a bare string), source link

**Synthetic data**:
Demo data generated by a script (courses, syllabi, documents); there is no real institutional data.
_Avoid_: Dữ liệu ảo, mock data

**Query rewrite**:
Rewriting a follow-up question into a standalone one using conversational memory, before retrieval.
_Avoid_: Câu hỏi tiếp nối, reformulation

**CRAG judge**:
An LLM pass that scores the retrieved chunks (high / medium / low) and decides whether to use them, refine the query, or refuse to answer.
_Avoid_: Evaluator, scorer, retrieval gate

**Refine**:
One retry with a rewritten query after the CRAG judge scores it medium or low; failing refine leads to refusal.
_Avoid_: Retry, second pass

**Answer check**:
A Self-RAG-style LLM verification that every claim in the draft answer is supported by the cited sources before the answer is returned.
_Avoid_: Self-RAG, verifier, fact-check

**Session**:
A per-user conversation context (last 6 turns) persisted in a simple database; the unit of conversational memory.
_Avoid_: Thread, conversation history

**User**:
A registered account (username + password) that owns Sessions in the demo database.
_Avoid_: Account, sinh viên

**Hybrid search**:
Retrieval that fuses BM25 (lexical) and dense vector scores via Reciprocal Rank Fusion (RRF), then re-ranks the fused list.
_Avoid_: Retrieval, search, two-tower
