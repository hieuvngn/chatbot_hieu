# CourseMate RAG Chatbot

A demo chatbot for IT students: advises on course selection and answers knowledge questions grounded in study materials, using a retrieval-augmented generation pipeline.

## Language

**Source**:
The unit of retrieved information that an answer cites — either a document chapter or a structured Entity (Instructor, Program, Term, Department). Every Source has a kind that tells the UI how to render it.
_Avoid_: Chunk, reference, context fragment

**Citation**:
The visible reference a generated answer carries back to its Source, shown in the UI and clickable by the user.
_Avoid_: Nguồn (as a bare string), source link

**Entity**:
A structured record (Instructor, Program, Term, Department) that the RAG pipeline can retrieve and cite, distinct from a document chapter. Lives in its own JSON file and is embedded/indexed alongside document chunks.
_Avoid_: Object, record, row

**Department**:
An organisational unit offering Courses (e.g. "Khoa Công nghệ thông tin"). Referenced by Instructor and Program via `department_id`.
_Avoid_: Faculty, school (avoid when ambiguous with academic faculty)

**Instructor**:
A person who teaches one or more Courses. May teach multiple Courses; a Course may list one or more Instructors (many-to-many via role). Referenced by Term via `instructor_id` when that term runs the Course.
_Avoid_: Teacher, lecturer, professor, giảng viên viết tắt

**Program**:
A curriculum grouping Courses into required and elective tracks, with a total-credits target. A Course may belong to multiple Programs (many-to-many) as required in one and elective in another.
_Avoid_: Major, ngành (when meaning curriculum), department

**Term**:
A specific semester offering (e.g. "Spring 2025") that lists which Courses run and who teaches each one in that Term. Overrides the default Course.instructor with a Term-specific instructor if listed.
_Avoid_: Semester (when meaning a specific calendar term), session

**Course advisory**:
The task of recommending and explaining Courses to a student from structured data (syllabus, credits, prerequisites). Task (a).
_Avoid_: Chọn môn, course selection, recommendation task

**Knowledge Q&A**:
The task of answering a student's question about a topic, grounded in study documents with visible Citations. Task (b).
_Avoid_: Material retrieval, hỏi đáp tài liệu

**Synthetic data**:
Demo data generated by a script (Courses, syllabi, documents, Entities); there is no real institutional data.
_Avoid_: Dữ liệu ảo, mock data

**Query rewrite**:
Rewriting a follow-up question into a standalone one using conversational memory, before retrieval.
_Avoid_: Câu hỏi tiếp theo, reformulation

**CRAG judge**:
An LLM pass that scores the retrieved chunks (high / medium / low) and decides whether to use them, refine the query, or refuse to answer.
_Avoid_: Evaluator, scorer, retrieval gate

**Refine**:
One retry with a rewritten query after the CRAG judge scores it medium or low; failing refine leads to refusal.
_Avoid_: Retry, second pass

**Answer check**:
A Self-RAG-style LLM verification that every claim in the draft answer is supported by the cited Sources before the answer is returned.
_Avoid_: Self-RAG, verifier, fact-check

**Session**:
A per-user conversation context (last 6 turns) persisted in a simple database; the unit of conversational memory.
_Avoid_: Thread, conversation history

**User**:
A registered account (username + password) that owns Sessions in the demo database.
_Avoid_: Account, sinh viên

**Hybrid search**:
Retrieval that fuses BM25 (lexical) and dense vector scores via Reciprocal Rank Fusion (RRF), then re-ranks the fused list. Operates over both document chunks and Entity chunks.
_Avoid_: Retrieval, search, two-tower
